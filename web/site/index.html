Every chip on the cards below was read off the surface it names — off the built definition, off the one recorded walk, or off the one table a person had to write — and each card says which. Nothing here was typed into this page. The CDC demo is two cards because it is two builds: the desk published here, with the disease co-occurrence graph, and the story page, built without it, which carries the only recorded walk this repository has. That page is its own build (npm run story:page) and is not published on this site.

What this build is, and is not

These pages are static. There is no server: each desk fetches the repository's own committed CSV files over http, runs the same shaping code the served version runs, and builds its dashboard in your browser. The first load of either desk therefore carries the whole snapshot, and it is not small.

Because nothing runs on the other end, three things are missing, and each desk says so on its own page:

  • the analyst — it needs a model key and a process to hold the conversation;
  • a durable log — your commits live in the tab and are gone when you reload;
  • a refresh — the files are what the repository committed, and re-reading them answers the same bytes.

Everything else is the real thing: selections, acts, undo, named paths, bookmarks, compare, the Sheet, the commit log and the branch map.
